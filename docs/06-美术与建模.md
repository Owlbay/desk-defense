# 06 · 美术与建模

## 1. 塔防游戏的"模型"一般是怎么做的

| 做法 | 工具 | 适合 | 优点 | 缺点 |
|---|---|---|---|---|
| **手绘位图 + 帧动画** | Aseprite、Photoshop、Krita | 像素风、手绘风 | 风格自由，表现力强 | 每个动作都要画多帧，工作量大 |
| **矢量图（SVG）+ 代码动画** | Figma、Illustrator、Inkscape，或者直接写 SVG | 扁平、几何风格 | 无限清晰，文件小，容易改配色和出变体 | 写实感弱 |
| **骨骼动画** | Spine、DragonBones | 需要复杂动作的角色 | 动作流畅，省素材 | 要额外学工具，Spine 收费 |
| **3D 建模** | Blender | 3D 塔防，或预渲染成 2D 图 | 立体感强，可以转任意角度 | 成本最高 |
| **程序化绘制** | 代码直接画形状（Phaser Graphics） | 原型、极简几何风 | 零素材，改数值就能改外观 | 细节一多，代码就难维护 |
| **AI 生成** | 图像生成模型 | 概念图、找方向 | 出图快 | 风格难统一，难拆成可动的部件 |

**本项目的选择：SVG 矢量部件 + 代码动画。**
- 几何风格天然适合矢量：一套 SVG 在手机和 4K 屏上都清晰。
- 每个塔或敌人拆成几个**命名图层**（底座、炮台、装饰、光效）。炮台旋转、开火后坐、呼吸光这类动作都由代码完成，**不需要画逐帧动画**。
- 游戏启动时把 SVG 按图层拆开，按当前屏幕像素密度和棋盘缩放画成纹理图集；缩放变化较大时重新生成，兼顾清晰度和手机性能。
- 素材由 AI 子代理按本规范批量绘制成 SVG，人工审核后放入 `art/`。

## 3. 素材规格

### 3.1 通用 SVG 规则
- `viewBox="0 0 128 128"`。防御塔对应 1 格（48 逻辑像素），留 8px 安全边距，主体放在中心 112×112 以内。
- 敌人：普通敌人主体直径约 56～72，飞行和大型敌人约 80～96，Boss 用 `viewBox="0 0 256 256"`。
- 描边：`stroke="#3B2F2A"`，宽度 4（T1）/ 4（T2）/ 5（T3、T4 外轮廓），`stroke-linejoin="round"`，`stroke-linecap="round"`。
- **禁止**：文字、外部引用、`<image>`、嵌入位图、CSS `<style>` 块。颜色全部写成行内属性。
- 允许：线性 / 径向渐变（只用于 T3、T4 和 Boss），`<filter>` 的高斯模糊（只用于 `glow` 图层）。
- 朝向：炮台类素材的**炮口统一朝上（−Y 方向）**，代码按目标方向旋转。
- 每个文件只放一个对象，不画背景。

### 3.2 图层命名（`<g id="...">`）
程序会按 id 取出各个部件分别做动画，所以必须遵守。

| id | 内容 | 是否必需 |
|---|---|---|
| `shadow` | 底部投影椭圆 | 必需 |
| `base` | 固定不动的底座 | 塔必需 |
| `body` | 主体（敌人的全部身体都放这里） | 必需 |
| `turret` | 会转向目标的部分，**旋转中心固定为 (64,64)** | 会瞄准的塔必需 |
| `accent` | 装饰件、等级标记位置 | 可选 |
| `glow` | 发光、光环（T3、T4） | T3、T4 必需 |
| `wing-l` / `wing-r` | 飞行敌人的翅膀，用来做扇动动画 | 飞行敌人必需 |

### 3.3 防御塔的形态视觉规则
| 形态 | 必须体现 |
|---|---|
| T1 草稿 | 单色平涂 + 描边；外形最简单；没有底座，或只有一块很淡的阴影 |
| T2 精良 | 加一个 `#6B5B4E` 圆角方形底座，边缘带青色线；主体双色；多 1～2 个零件 |
| T3 镀金 | 金色描边和装饰；主体用渐变；部件翻倍或加大；`glow` 图层放一圈淡金光 |
| T4 传奇 A / B | 轮廓明显不同于 T3；A 用青色光，B 用品红光；`glow` 图层里有光环和 3～6 个粒子点 |

### 3.4 文件命名
```
art/towers/{塔id}_t1.svg  _t2.svg  _t3.svg  _t4a.svg  _t4b.svg
art/towers/wall_l1.svg  wall_l2.svg  wall_l3.svg
art/enemies/{敌人id}.svg        art/enemies/boss_{id}.svg
art/affixes/{词缀id}.svg        art/skills/{技能id}.svg
```
**塔 id**：wall、pencil、stapler、glue、lamp、compass、eraser、ruler、pen、calculator、piggy、swatter

**敌人 id**：crumb、inkdot、paperclip、plane、paperball、sticky、rubberband、whiteout、ant、invisink、tape、moth

**Boss id**：coffee、shredder、inkbottle、alarm

**词缀 id**：hard、swift、regen、shield、split、stealth、reflect、unstoppable、rally

**技能 id**：eraser_strike、bell、whiteout_zone、caffeine、ruler_sweep、scholarship、relocate、inspiration、magnifier

## 4. 动画（全部由代码实现）

| 对象 | 动画 |
|---|---|
| 塔放下 | 从 0.6 倍弹到 1.1 倍再回到 1 倍，用时 180 毫秒，伴随一圈灰尘 |
| 炮台瞄准 | `turret` 平滑转向目标，每秒最多转 720° |
| 开火 | `turret` 后坐 2px，用时 60 毫秒后回位；炮口闪一下白色圆点 |
| T3 呼吸光 | `glow` 透明度在 0.3～0.7 之间循环，周期 2 秒 |
| T4 光环 | `glow` 缓慢自转，粒子点上下浮动 |
| 换形态 | 缩小、闪白、新外观弹出，冒纸屑粒子 |
| 敌人行走 | `body` 上下浮动 2px，并在 ±4° 之间摆动 |
| 飞行敌人 | `wing-l` / `wing-r` 沿纵向拉伸，模拟扇动，周期 0.25 秒 |
| 受击 | 整体着色变白 80 毫秒 |

## 5. 素材生产流程

1. **规范**：就是本章。
2. **绘制**：AI 子代理按规范批量输出 SVG，并逐个渲染成缩略图自查。
3. **预览**：`art/gallery.html` 把所有素材按"塔 × 形态"、"敌人"、"词缀"、"技能"排成表格，方便一眼对比风格是否统一。
4. **审核**：人工看预览页，提出修改意见，再让子代理返工。
5. **入库**：SVG 直接放进 `art/`，游戏运行时自动拆图层、生成纹理（见 `src/render/assets.ts`），不需要额外的构建步骤。
