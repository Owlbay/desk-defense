# 01 · 概述与核心玩法

## 1. 概述

| 项目 | 内容 |
|---|---|
| 名称 | 书桌防线（Desk Defense） |
| 类型 | 迷宫式塔防，带养成元素和随机增益（类 Roguelite） |
| 题材 | 书桌上的文具大战桌面上的"小麻烦" |
| 风格 | 几何扁平风，SVG 矢量部件加代码动画 |
| 平台 | Web 优先，支持手机、平板、电脑；之后打包成 PWA、iOS / Android 和桌面应用 |
| 单局时长 | 战役一关约 15～20 分钟；无尽模式不限 |

**卖点**
1. **自己造迷宫**：塔就是墙，路线由玩家决定。
2. **塔会成长**：打怪攒经验，从"草稿"进化到"传奇"，有 4 种外观。
3. **每局不一样**：随机增益三选一、精英词缀、随机种子。
4. **难度阶梯**：从简单到魔境 X，所有成长比例都可以调整。

## 2. 核心循环

```
┌─ 准备阶段 ─────────────────────────────┐
│ 放塔、造墙、升级、卖塔；查看下一波预告       │
└──────────────┬────────────────────────┘
               │ 点「开始下一波」（提前开有奖励）
┌─ 战斗阶段 ────▼────────────────────────┐
│ 敌人按流场寻路；塔自动攻击并获得经验         │
│ 玩家可以继续放塔，或者释放主动技能           │
└──────────────┬────────────────────────┘
               │ 本波敌人全部被消灭或漏掉
┌─ 结算 ────────▼────────────────────────┐
│ 清波奖励 + 利息 + 存钱罐产出               │
│ 每 10 波：局内增益三选一                    │
└──────────────┴──→ 回到准备阶段
```

- **失败**：生命归零。
- **胜利**：战役模式撑过第 20 波；无尽模式没有胜利，只看撑到第几波和得分。
- 波次之间**没有强制倒计时**，节奏由玩家掌控，手机上被打断也不会吃亏。

## 3. 地图与网格

| 项目 | 设定 |
|---|---|
| 网格 | **12 列 × 14 行**，所有平台通用同一张地图 |
| 格子 | 逻辑尺寸 48px，按屏幕大小整体缩放 |
| 入口 | 顶边，宽 2 格，有的章节有两个入口 |
| 出口 | 底边中间的作业本，宽 2 格 |
| 固定障碍 | 每章不同（水杯、键盘、调色盘……），不能建造 |

### 3.1 寻路
- 从出口倒推，用 Dijkstra 生成**流场**：8 个方向，斜走代价 1.414，**不能贴着墙角斜穿**。
- 放塔、卖塔、搬家之后重新计算流场。格子总共 168 个，计算耗时可以忽略。
- 地面敌人记录"当前格"和"目标格"，到达目标格中心后再取流场的下一格。所以流场变化时敌人不会瞬移，而是走完当前这一步再转向。
- 多入口的地图共用同一张流场（流场从出口倒推，与入口无关）。

### 3.2 放置校验
以下情况**不能**放塔：
1. 入口、出口、固定障碍，或者已经有塔的格子
2. 任何地面敌人当前所在的格子，或者它正要走向的格子
3. 放下后，任意一个入口走不到出口
4. 放下后，场上有地面敌人走不到出口

不能放置时，预览变成红色，并用一句话说明原因（"会堵死道路"、"有敌人在这里"）。

## 4. 操作

### 4.1 鼠标和触摸统一
| 动作 | 电脑 | 手机 / 平板 |
|---|---|---|
| 选择要建的塔 | 点塔栏，或按数字键 1–9、0、- | 点塔栏 |
| 放塔 | 悬停显示预览和射程，点击放下；按住 Shift 可以连续放 | 点一下格子显示预览，**再点同一格确认**；点别的格子会把预览移过去 |
| 选中已有的塔 | 点击 | 点击 |
| 取消 | 右键或 Esc | 点空白处，或再点一次塔栏里已选中的按钮 |
| 释放技能 | Q / W / E / R，或点按钮 | 点按钮 → 点位置预览 → 再点确认 |
| 开始下一波 | 空格 | 点按钮 |
| 加速 / 暂停 | F / P | 点按钮 |
| 缩放棋盘 | 不需要（自动适配） | 不需要；棋盘固定显示全图 |

- **误触保护**：放下塔后 5 秒内可以撤销并全额退款。
- **不依赖悬停**：所有只在悬停时显示的信息，触摸设备上都改为"选中后显示"。

### 4.2 游戏速度
1×、2×、3×，以及暂停。逻辑以固定步长运行，加速就是每帧多跑几步，所以不同速度下的结果完全一致。

## 5. 界面布局

```
竖屏（手机）                          横屏（电脑 / 平板）
┌──────────────────────┐             ┌──────────────────────┬──────────┐
│ ❤20  💰150  🌊12  ⏸ │             │                      │ ❤ 💰 🌊 ⏸│
├──────────────────────┤             │                      ├──────────┤
│                      │             │                      │ 塔列表     │
│        棋盘           │             │        棋盘           │（两列网格）│
│      12 × 14         │             │      12 × 14         │          │
│                      │             │                      ├──────────┤
├──────────────────────┤             │                      │ 选中信息    │
│ 选中信息 / 升级 / 出售   │             │                      │ 升级 / 出售  │
├──────────────────────┤             │                      ├──────────┤
│ [塔栏，可横向滑动]       │             │                      │ 技能 Q W E │
│ [技能1][技能2][技能3]    │             │                      │ 下一波预告   │
│ 下一波预告   ▶开波  ⏩   │             │                      │ ▶开波  ⏩   │
└──────────────────────┘             └──────────────────────┴──────────┘
```

- 宽高比大于 1.1 时用横屏布局，否则用竖屏布局，旋转屏幕时实时切换。
- 按钮最小 44×44px；塔按钮显示图标、价格，金币不够时置灰。
- **选中信息**包括：名称、等级、形态、经验条、伤害 / 攻速 / 射程，目标策略切换，以及升级（显示价格和经验折扣）和出售（显示返还金额和返还率）按钮。到 Lv9 时，升级按钮变成"选择传奇分支"，并展示两个分支的卡片。
- **结束画面**：撑过的波数、得分、击杀数、塔的伤害排行（谁是 MVP）、"再来一局"、"换难度"。

## 6. 新手引导

| 关卡 | 教学内容 |
|---|---|
| 1-1 | 放铅笔，开第 1 波 |
| 1-2 | 用书本墙改路线（会高亮显示路线的变化） |
| 1-3 | 升级塔；看经验条涨 |
| 1-5 | 卖塔（提示返还率随等级下降） |
| 1-10 | 第一次 Boss，并引导使用技能"大橡皮" |

引导只出现一次，可以在设置里重置。
