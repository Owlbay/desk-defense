# 台灯重做：给 AI 速查表的要点（src/agent 负责人请并入 cheat sheet）

- 台灯 lamp（80 金）现在是**持续光束**：`TOWERS.lamp.damage` = Lv1 秒伤 13（interval 固定 1），每 0.1 秒结算，无视护甲、打空中、对飞蛾 ×2、1.5 格侦测隐形。
- **递增**：照同一目标每秒 +60%，最多 ×3；目标死亡 / 离开清零（Lv4 余温保留 50%）。Lv7 双灯头 = 第二道 50% 光束。适合 Boss / 高护甲 / 长直道，不适合成群小怪和快怪。
- **联动**：中心距 ≤ 2.5 格的台灯自动成组（可链式），普通组最多 4 座。目标走得最远的当主灯，没有目标或同目标的组员当辅灯，把光并进主灯：主灯 ×(1 + Σ 1.1·k^-0.25·辅灯秒伤/主灯秒伤)，4 座同级 ≈ ×3.9，递增上限 +0.75/座（最多 +2.25）。
- **摆放建议**：Boss 路线旁 3～4 座台灯两两相隔约 2 格（如 (x,y)、(x+2,y)、(x,y+2)）；离路线较远的灯也能当辅灯。被咖啡泼 / 台灯跳闸的灯会断开链。
- **传奇 A 激光笔**：基础秒伤 ×0.6，递增 +100%/秒、上限 ×5（★1 ×7.5），当主灯时效率 ×1.1；**有激光笔的连通块不限座数**，每多一座仍有加成（递减）。★3「过载」= 整组 8 秒递增拉满 + 每座光束分裂 4 道、伤害 ×2（冷却 60 秒，Boss 进入光棱阵时放）。
- **传奇 B 护眼灯**：基础秒伤 ×0.7，整射程反隐，照到的敌人易伤 +15%（★1 +25%）；联动时组内所有光束都挂标记，当主灯时光束分裂出（辅灯数）道 35% 短光束。★3「白昼」不变（全图反隐 + 易伤 +300%，8 秒）。
- 状态字段：`TowerState.prism`（组号，单独为 0）、`prismSize`、`prismLead`（正在汇聚的主灯 uid）、`prismRelay`（主灯上的汇聚倍率）；事件 `beam` 多了 `ramp/relay/group`，新增 `prismLink {from,to}`。数值在 `src/config/towers.ts` 的 `LAMP` 与 `BRANCH.lamp`。
