**书桌防线（Desk Defense）** 是一款以书桌为舞台的**迷宫式塔防**游戏：铅笔、订书机、胶水瓶、台灯……桌上的文具组成防线，对抗橡皮屑、墨点、纸飞机、咖啡渍等"小麻烦"，守住桌子底部的**作业本**。

和"沿固定道路摆塔"的塔防不同，这里**塔本身就是墙**——你放下的每一座塔都会改变敌人的路线。路线怎么绕、在哪里设伏，全由你决定。

---

## 游戏亮点

| 亮点 | 说明 |
|---|---|
| 自己造迷宫 | 12 × 14 的棋盘上自由摆塔，塔会挡路。用便宜的书本墙把路绕长，让敌人在火力圈里多转几圈。唯一的限制：不能把路完全堵死。 |
| 塔会成长 | 每座塔打怪攒经验，从 **草稿 → 精良 → 镀金 → 传奇（A / B 两个分支）** 进化，传奇之后还能升星，★3 成为**神话**并获得主动能力。每个阶段外观都不同。 |
| 12 座塔 | 单体、群伤、减速、穿甲、环形切割、破甲、远程穿透、持续伤害、增益光环、经济、专职防空，再加上造迷宫的书本墙。 |
| 每局都不一样 | 杂物按种子随机摆放；每 10 波从随机增益里三选一；高难度下精英怪带随机词缀；战斗中还会发生 15 种随机事件（空降纸箱、台灯跳闸、掉落零花钱……）。 |
| 难度阶梯 | 战役 3 章 → 无尽模式 简单 / 普通 / 困难 / 噩梦 / 魔境 I～X，另有可以拖滑块自定义一切参数的自定义模式。 |
| 长期养成 | 战役评星赚**星星**，无尽模式赚**墨水**，用来升级永久天赋（书包）和主动技能。 |

## 平台与安装

| 平台 | 说明 |
|---|---|
| 电脑浏览器 | 鼠标 + 键盘，支持全套快捷键（见 [常见问题 · 快捷键](09-常见问题.md#快捷键一览)）。 |
| 手机 / 平板浏览器 | 触摸操作，所有放置和瞄准都是"点一下预览、再点同一处确认"，不怕误触。横屏和竖屏都能玩，旋转屏幕时界面自动切换布局。 |
| PWA（添加到主屏幕） | 游戏支持"安装"为 PWA：全屏运行，首次加载后**可以离线游玩**。安装方法见 [常见问题 · 离线与安装](09-常见问题.md#离线与安装)。 |

所有平台使用同一张 12 × 14 的棋盘，存档保存在当前浏览器本地。

## 怎么开始

1. 打开游戏，在主菜单点 **「战役」**，选择 **第一章 · 学生书桌 · 普通**。
2. 跟着新手引导的气泡提示：放一座铅笔塔 → 开始第 1 波 → 用书本墙改路线 → 升级 → 出售。
3. 通关第一章后，**无尽模式**和**自定义模式**解锁，书包（天赋）和技能页也有了用武之地。

第一次玩建议从 [01 新手入门](01-新手入门.md) 读起，只需要 5 分钟。

> **也可以在游戏里看**：主菜单 →「图鉴 / 玩法」是本指南的游戏内版本——可搜索、跟随界面语言（简体中文 / 繁體中文 / English / 日本語），塔的数值直接从当前版本读出。也能用链接直达某一条，例如 [铅笔塔](https://jjjj.games/#guide/tower/pencil)、[咖啡渍](https://jjjj.games/#guide/enemy/boss_coffee)。
