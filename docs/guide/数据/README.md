## 如何生成

```bash
npm run docs:data
# 等价于
npx vite-node scripts/gen-data-docs.ts
```

- 生成器导入 `src/core` 与 `src/config` 的真实导出；塔的逐级数值、升级费用、出售返还、进化费用、组合加成都是在临时对局（`createWorld`）里实际放塔、升级、进化后从 `getTowerInfo()` 读出的。
- 波次与布局使用固定种子（`docs`、`docs-sample`、`docs-1..3`），重复运行结果相同。
- 修改了平衡数值后重新运行即可，不要手改这些文件。
