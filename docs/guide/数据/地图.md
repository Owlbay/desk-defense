# 地图

每张地图的固定骨架（出生点、出口、标志物）、随机杂物池与布局规则，以及用 `generateLayout` 按固定种子生成的 3 个示例布局。

> 返回 [数据索引](./README.md)

图例：`S` 开局开放的入口，`L` 后期开放的入口，`H` 暗门（事件开启的隐藏出生点），`E` 出口，`.` 空地，`*` 开局时敌人的地面路线；障碍物：`e` 橡皮，`s` 便利贴，`c` 回形针，`u` 笔筒，`t` 胶带，`h` 手机，`x` 订书机，`r` 直尺，`C` 水杯，`B` 课本，`K` 键盘，`M` 鼠标，`P` 调色盘，`p` 颜料管。坐标 x 向右 0–11，y 向下 0–13。

## 布局规则

| 规则 | 数值 |
|---|---|
| 每个开局入口到出口的路线长度 | 14～30 格（后期入口也不超过 30） |
| 可建造空地比例 | ≥ 70% |
| 单格宽缺口 | ≤ 4 个 |
| 杂物间距 | 杂物与杂物、标志物之间至少隔 1 格；出生点与出口周围 1 格内不放 |
| 重试 | 每件杂物最多尝试 50 个位置；整张布局最多重试 20 次，失败则用手工默认布局 |
