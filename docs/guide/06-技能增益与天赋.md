# 06 · 技能、增益与天赋

除了放塔，你还有三层能力：

| 层次 | 持续 | 获取 | 作用 |
|---|---|---|---|
| **主动技能** | 一局内，靠冷却反复用 | 开局带入 3 个（天赋可扩到 4 个） | 关键时刻救场 |
| **局内增益** | 一局内永久 | 每 10 波三选一 | 让每局打法不同 |
| **永久天赋（书包）** | 跨局保存 | 用星星或墨水购买 | 小幅长期加成 |

另外，神话塔的主动能力见 [03 防御塔图鉴](03-防御塔图鉴.md#13-传奇之后进化与神话)。

## 1. 主动技能

### 1.1 规则

- 在主菜单 **「技能」** 页选择带入的技能（最多 3 个，天赋「大书包」解锁第 4 个；至少带 1 个）。没有调整过时默认带 **大橡皮、下课铃、涂改液**。
- 技能不花金币，用**冷却**控制。**开局时全部就绪**。
- **冷却只在战斗进行中计时**——波次之间的准备阶段不走冷却。
- 冷却时长 = 基础冷却 × 难度技能冷却倍率（简单 0.8 … 魔境 X 约 1.38），再受技能等级、天赋「闹钟提醒」、增益「快速复习」缩短。
- **伤害缩放**：大橡皮和横扫尺的伤害 × 当前波次的"敌人生命倍率"，所以后期依然有用。
- 操作：电脑点按钮或按 **Q / W / E / R** 进入瞄准，点棋盘释放，右键 / Esc 取消；手机点按钮 → 点棋盘预览 → 再点一次确认，点技能按钮取消。全场生效的技能点一下直接释放。

### 1.3 技能升级

在「技能」页用**墨水**升级，每个技能最高 Lv3：Lv1→2 **100 墨水**，Lv2→3 **250 墨水**。

每升 1 级：**冷却 −8%**，**效果 +15%**。"效果"具体指：

| 技能 | 升级提升的是 |
|---|---|
| 大橡皮、横扫尺 | 伤害 |
| 下课铃 | 眩晕时长 |
| 涂改液、放大镜、咖啡因 | 持续时间 |
| 奖学金 | 金币数 |
| 灵感闪现 | 给予的经验量 |
| 封箱胶带 | 只缩短冷却 |
| 搬家 | 充能次数 2 → 3 → 4（没有冷却） |

### 1.4 带什么技能

| 情况 | 推荐 |
|---|---|
| 新手 / 通用 | 大橡皮 + 下课铃 + 涂改液 |
| 迷宫流 | 下课铃 + 涂改液 + 搬家 |
| 输出爆发 | 大橡皮 + 咖啡因 + 放大镜 |
| 经济 / 养成 | 奖学金 + 灵感闪现 + 下课铃 |
| 困难以上（空降多） | 加带 **封箱胶带**——拆一个空降点要 `40 + 5 × 波数` 金，胶带免费 |
| 隐形多（第三章、魔境） | 放大镜或涂改液 |
| 第 4 槽（大书包） | 下课铃 / 封箱胶带 / 大橡皮中补一个 |

> 技巧：Boss 半血分裂、墨水瓶隐身、闹钟响铃加速——这些"阶段转换"的瞬间是放大橡皮和下课铃的最佳时机。

## 2. 局内增益（三选一）

### 2.1 什么时候选

- **无尽 / 自定义**：每 10 波结束后一次。
- **战役**：第 10 波结束后一次。
- 选择时游戏暂停（自动开波的倒计时也暂停）。
- 可以花 **50 金** 刷新一次选项（天赋「幸运签」：每次选择的第一次刷新免费）。天赋「文具收藏家」把三选一变成**四选一**。
- 同一个增益一局只能拿一次（「零花钱」除外）。「传奇在望」只在场上有 Lv7～9 的塔时出现；「二次元口袋」只在还有没带的技能时出现。

### 2.2 稀有度

| 稀有度 | 出现权重 |
|---|---|
| 普通 | 60 |
| 稀有 | 30 |
| 史诗 | 10（第 30 波以后 15） |

### 2.3 全部增益

| 增益 | 稀有度 | 效果 | 什么时候拿 |
|---|---|---|---|
| 削笔刀 | 普通 | 铅笔塔伤害 +20% | 场上铅笔 ≥ 3 座，或主 C 是自动铅笔 |
| 快干胶 | 普通 | 胶水减速 +10%，持续 +0.5 秒 | 迷宫 / 控制流 |
| 加厚书皮 | 普通 | 书本墙造价降为 3，升级费 −30% | 还要继续扩迷宫、或要大量升 Lv3 墙 |
| 零花钱 | 普通 | 立即获得 `50 + 5 × 波数` 金（可重复） | 急需一波钱；后期数额可观 |
| 复习笔记 | 普通 | 所有塔获得经验 +15% | 养成流；越早拿越值 |
| 早起的鸟 | 普通 | 提前开波奖励 ×2 | 速推流、自动开波 |
| 节能灯泡 | 稀有 | 台灯攻击间隔 −20% | 有多座普通 / 护眼灯台灯（**对激光笔无效**，激光笔是持续光束） |
| 订书钉补充装 | 稀有 | 订书机眩晕概率 +10% | 多座订书机；Lv4 前也能让订书机有眩晕 |
| 利滚利 | 稀有 | 利息比例 5% → 8%，上限 +10 | 经济流；手里常有 300+ 金 |
| 打折季 | 稀有 | 所有塔造价、升级、进化费用 −10% | 几乎永远不亏，后期堆传奇 / 神话时尤其好 |
| 快速复习 | 稀有 | 所有技能冷却 −15%（搬家除外） | 依赖技能的打法 |
| 保险箱 | 稀有 | 生命 +5（最大生命也 +5） | 生命告急 |
| 精确制图 | 稀有 | 尺子、圆规射程 +0.5 | 尺规直道流、圆规迷宫 |
| 墨水管够 | 稀有 | 钢笔墨迹最大层数 +2 | 有多座钢笔 |
| 全员晋升 | 史诗 | 场上所有塔立即升 1 级（最多到 Lv9；墙最多 Lv3） | 塔多的时候拿最赚；免费升级不计入出售投入 |

## 3. 永久天赋（书包）

### 3.1 货币

| 货币 | 获得 | 用途 |
|---|---|---|
| ⭐ 星星 | 战役评星（每章普通、困难各最多 3 颗，共 18 颗） | 购买天赋 |
| 💧 墨水 | 无尽 / 自定义结束时结算：`撑过的波数 × 难度系数`（简单 0.5、普通 1、困难 1.5、噩梦 2、魔境 3），向下取整 | 购买天赋、升级技能 |

### 3.2 天赋表

天赋每一级都可以选择用**星星或墨水**购买。

| 天赋 | 每级效果 | 最高 | 每级价格 |
|---|---|---|---|
| 零钱包 | 初始金币 +5% | 5 级 | 2 ⭐ 或 40 💧 |
| 创可贴 | 初始生命 +1 | 3 级 | 3 ⭐ 或 60 💧 |
| 闹钟提醒 | 技能冷却 −3% | 5 级 | 2 ⭐ 或 50 💧 |
| 勤学 | 塔获得经验 +5% | 5 级 | 2 ⭐ 或 50 💧 |
| 二手市场 | 卖塔返还率 +2% | 3 级 | 3 ⭐ 或 60 💧 |
| 大书包 | 解锁第 4 个技能槽 | 1 级 | 6 ⭐ 或 200 💧 |
| 幸运签 | 每次增益选择的第一次刷新免费 | 1 级 | 4 ⭐ 或 120 💧 |
| 文具收藏家 | 局内增益变成四选一 | 1 级 | 8 ⭐ 或 300 💧 |

- 全部点满需要 66 颗星（或等价墨水），而战役最多只给 18 颗——**星星优先买单级大件**（大书包、文具收藏家、幸运签），多级的小加成用墨水慢慢补。
- 推荐顺序：大书包 → 文具收藏家 → 勤学 → 零钱包 → 闹钟提醒 → 幸运签 → 创可贴 → 二手市场。

### 3.3 纯净模式

无尽模式开局时可以打开 **「纯净模式」**：关闭所有永久天赋（包括大书包的第 4 个技能槽），成绩进入单独的**纯净排行榜**。技能等级不受影响。
