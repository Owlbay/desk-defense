# 09 · 常见问题

---

## 存档

### 进度保存在哪里？会丢吗？
- 所有进度（战役星星、墨水、天赋、技能等级、排行榜、设置、中途存档）都**自动保存在当前浏览器本地**，不需要登录。
- 主菜单底部会显示"进度自动保存在本机"。如果显示"当前浏览器无法保存进度（隐私模式？）"，说明浏览器禁止了本地存储（常见于无痕 / 隐私模式），关掉页面后进度会丢失。
- 以下操作会**清空进度**：清除浏览器的网站数据 / 缓存、卸载已安装的 PWA（部分系统）、在设置里点「清除存档」。
- 不同浏览器、不同设备之间**不会同步**；目前也没有云存档。在部分系统（如 iOS）上，"添加到主屏幕"的应用和浏览器里打开的游戏可能各有一份独立的存档。

### 怎么清除存档重新开始？
主菜单 → **设置** → 存档 → **「清除存档」**，确认后战役星星、墨水、天赋、技能等级、排行榜和中途存档都会被删除，**无法恢复**。

## 离线与安装

### 能离线玩吗？
可以。游戏是 PWA：联网打开一次后，所有资源会缓存到本机，之后**断网也能玩**。有新版本时，下次联网打开会自动更新。

### 怎么安装到桌面 / 主屏幕？
| 设备 | 方法 |
|---|---|
| iPhone / iPad（Safari） | 点底部的 **分享** 按钮 → **「添加到主屏幕」** |
| Android（Chrome） | 点右上角菜单 → **「安装应用」** 或 **「添加到主屏幕」**（有时地址栏下方会直接弹出安装提示） |
| 电脑（Chrome / Edge） | 点地址栏右侧的 **安装** 图标，或菜单 → 「安装书桌防线」 |

安装后从桌面图标打开，游戏会**全屏运行**，没有浏览器地址栏。

## 对局

### 打到一半退出了，还能继续吗？
可以。**每打完一波**会自动保存一次中途存档。回到主菜单，第一个按钮就是 **「继续游戏」**，会显示"模式 · 地图 · 难度 · 第 N 波后"。

- 恢复的是**上一波结束时**的状态（游戏会用种子和你的操作记录快速重演到那一刻，所以结果完全一致）。
- **还没打完第一波**就退出，不会保留进度。
- 中途存档只保留一局；开始新的一局并打完一波后，旧的会被覆盖。
- 切到其他应用 / 标签页时游戏会自动暂停，不会在后台漏怪。

### 为什么这里放不了塔？
放置失败时格子会闪红，并显示原因：

| 提示 | 原因 |
|---|---|
| 会堵死道路 | 放下后某个入口（包括还没开放的侧入口、空降点）走不到作业本 |
| 会困住敌人 | 放下后场上某个地面敌人无路可走 |
| 有敌人在这里 | 地面敌人正站在这格，或正要走进这格 |
| 这里不能建造 | 入口、作业本、杂物、已落地的纸箱 |
| 已经有塔了 | 这格已经有塔 |
| 出生点即将出现在这里 | 空降纸箱正在这格预警 |
| 金币不足 | 钱不够 |
| 尚未解锁 | 战役里这座塔还没到解锁波数（塔栏按钮会显示"战役 X-Y 解锁"） |
| 存钱罐最多 3 个 | 存钱罐数量上限 |

### 为什么我的塔打不到飞行敌人？
- **只有这些塔能打空中**：铅笔、台灯、尺子、钢笔（地空皆可），苍蝇拍（只打空中）。胶水、订书机、圆规、橡皮擦**只打地面**。
- 飞行敌人不走迷宫，而是从入口**直线**飞向作业本——如果塔离这条直线太远，就够不着。把防空塔放在作业本上方，所有航线都会在那里汇合。
- 被**捕虫网**网住的敌人暂时变成地面单位：这时苍蝇拍打不到它，要靠地面塔。
- 飞蛾会闪避 25% 的铅笔 / 钢笔子弹；「窗外起风」期间追踪弹会落空。
- 隐形的飞行精英需要先被侦测。

### 为什么我的塔突然不打了？
- **瘫痪**：咖啡渍 Boss 的泼洒（2 秒）、事件「咖啡打翻」（6 秒），被瘫痪的塔会盖上一层棕色。
- **台灯跳闸**：所有台灯停用 8 秒。
- 目标是**隐形**的，或是正在**弹跳**的橡皮筋。
- 目标不在射程内（选中塔可以看到射程圈）。

### 技能冷却为什么不走？
技能冷却（以及神话塔能力的冷却）**只在战斗进行时计时**，波次之间的准备阶段不走。开局时所有技能都是就绪的。

### 传奇分支选错了能改吗？
不能。分支一旦选定就不能更改；想换只能卖掉重造（Lv10 返还率 25%）。升级到 Lv10 前会弹出两张分支卡片，仔细看说明再选。

### 自动开波太快了，能关掉吗？
可以。设置 → 对局 → **开波方式**：按难度 / 自动 / 手动。也可以在开局页直接切换开关。对局中修改设置**下一局生效**。注意排行榜按开波方式分开记录。

### 战役的杂物每次位置都不一样？
是的，杂物按种子随机。想每次都一样：设置 → 对局 → 打开 **「战役固定布局」**（只影响战役）。

### 怎么和朋友打同一局？
- 无尽：把**种子**发给朋友（暂停菜单、结算画面、排行榜里都能复制），朋友在开局页"随机种子"里填入即可，地图要选同一张。
- 自定义：再加上**分享码**，规则也完全一样。

## 画面与性能

### 手机发热 / 卡顿怎么办？
- 设置 → 画质 → **「低（省电）」**：关闭发光层和大部分粒子特效，降低渲染分辨率，适合老手机。
- 少开 3× 速度。
- 为了保证流畅，场上最多同时存在 150 个敌人；一波敌人超过 200 个时会自动合并成"×k 兵团"，压力不变。

### 声音太大 / 想关音乐？
设置 → 声音：**音效**和**音乐**两个音量滑块，拉到 0 即关闭。

### 横屏还是竖屏？
都支持。屏幕宽高比大于约 1.1 时用横屏布局（右侧面板），否则用竖屏布局（下方面板），旋转屏幕时实时切换。

## 新手引导

### 怎么重新看一遍新手引导？
设置 → 存档 → **「重置新手引导」**，下次进入战役第一章时会重新出现。

引导内容：放一座铅笔塔 → 开始第 1 波 → 用书本墙改路线 → 让塔成长 → 出售与撤销 → Boss 与大橡皮。另外在任何模式里第一次遇到随机事件、空降纸箱、塔升到传奇时，都会弹出一次性提示。

## 快捷键一览

| 按键 | 作用 |
|---|---|
| **1** | 书本墙 |
| **2** | 铅笔塔 |
| **3** | 订书机 |
| **4** | 胶水瓶 |
| **5** | 台灯 |
| **6** | 圆规 |
| **7** | 橡皮擦 |
| **8** | 尺子 |
| **9** | 钢笔 |
| **0** | 计算器 |
| **-** | 存钱罐 |
| **=**（或 +） | 苍蝇拍 |
| 再按一次同一个数字键 | 取消建造 |
| **Q / W / E / R** | 第 1～4 个技能 |
| **T** | 横扫尺瞄准时切换横向 / 纵向 |
| **空格** | 开始下一波 / 提前开波；鼠标悬停在硬币或补给箱上时为收集 |
| **F** | 切换速度 1× → 2× → 3× |
| **P** | 暂停；暂停菜单中按 P 或 Esc 继续 |
| **U** | 升级选中的塔（Lv9 时打开传奇分支选择；传奇后为进化） |
| **S** | 出售选中的塔（无需二次确认） |
| **A** | 释放选中神话塔的主动能力 |
| **Esc** / 右键 | 取消当前操作（瞄准、建造、选中）；分支选择窗口中为关闭 |

> 未解锁或金币不足的塔，按对应数字键会提示原因。
