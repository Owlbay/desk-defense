# 09 · 动态战场：多点出怪、空降出生点、随机事件、自动波次、随机地形

> 状态：**设计稿，尚未实现**。本章扩展第 01、03、04 章；凡是与旧规则冲突的地方，以本章为准。

## 0. 目标

| 需求 | 本章方案 |
|---|---|
| 多个地方出怪，也可以随机 | 每张地图有多个**出生点**，每组敌人从哪个出生点出来，可以固定、轮流或随机（§1） |
| 空降一个出生地 | 战斗中可以**空降出生点**：先预警，再落地，然后开始出怪，同时改变路线（§2） |
| 页面上的随机事件 | 用**事件导演**按种子安排随机事件，页面上有横幅、时间轴和可点击的掉落物（§3） |
| 正式开始后自动出怪，并有上限时间 | **自动波次**：第一波由玩家开始，之后按倒计时自动开下一波，每波有时间上限（§4） |
| 随机障碍物不能每局都一样 | **随机地形生成**：同一张地图的杂物每局按种子重新摆放，并保证可玩（§5） |

所有新机制都放在 `src/core` 里，并遵守**确定性**：随机数只来自局内的种子，所以同一个种子加同一串指令仍然能完整复现一局。这对回放、中途存档和 Agent 对战（第 10 章）都很重要。

## 1. 多出生点

### 1.1 概念
| 名词 | 含义 |
|---|---|
| **出生点（Spawner）** | 敌人出现的位置，占 1～2 格。分三种：**边缘入口**（桌边，固定）、**空降出生点**（战斗中临时出现）、**隐藏出生点**（地图里预置但默认关闭，由事件激活） |
| **出口（Exit）** | 作业本，保持每张地图一个。流场只从出口倒推，所以出生点再多也只需要一张流场 |
| **出怪策略** | 每组敌人选择出生点的方式 |

### 1.2 出怪策略
| 策略 | 说明 | 用在哪里 |
|---|---|---|
| `fixed` | 指定某个出生点 | 战役手工编排的波次 |
| `roundRobin` | 在所有开放的出生点之间轮流（忽略权重） | 简单难度 |
| `random` | 每个敌人按权重随机挑一个出生点 | 普通及以上难度（默认） |
| `split` | 同一组敌人平均分到各个出生点，同时出现 | "包夹波" |
| `focus` | 整组都从同一个随机出生点出来 | "突袭波" |

- 下一波预告会**按出生点**显示敌人，比如"左入口 橡皮屑×6 / 右入口 墨点×4"。棋盘上对应的出生点会亮起，并显示小图标。
- 随机的结果在**波次生成时就确定**，并写进预告，玩家看到的就是实际会发生的。
- 难度参数新增 `spawnMode`（默认策略）和 `maxActiveSpawners`（同时开放的出生点上限）。

### 1.3 地图数据变化
```ts
interface SpawnerDef {
  id: string;                    // 'north' | 'west' | 'hidden-1' …
  cells: { x: number; y: number }[];
  kind: 'edge' | 'hidden';
  weight: number;                // random 策略下的权重
  openFromWave?: number;         // 从第几波开始开放（默认 1）
}
```
新增"侧边入口"：左边或右边桌沿也可以出怪，让多点出怪真正形成包夹。为了保证可玩，出生点与出口的直线距离至少 **8 格**。

侧边入口的权重为 **0.4**（北边主入口为 1），无尽模式里第一章第 25 波、第二 / 三章第 30 波开放（战役第二章第 15 波、第三章第 16 波）。侧边入口带来一条新的斜向飞行路线，绕开了沿主入口建好的防空，所以权重要压低：平衡模拟里权重 0.6 + 轮流出怪（每个入口平分）时，普通 · 中等策略会在第 42 波（闹钟 Boss 之后的空袭波）集中崩盘。

## 2. 空降出生点

### 2.1 生命周期
```
预警（虚线圈 + 倒计时 5 秒，可以在这期间调整防线）
   → 落地（纸箱从天而降，落点 3×3 范围内的敌人被推开，墙不受影响）
   → 激活（之后若干波，部分敌人从这里出来）
   → 关闭（持续波数结束，或被玩家"拆除"）
```

### 2.2 规则
| 规则 | 数值 / 说明 |
|---|---|
| 落点选择 | 只能落在空地上；距离出口至少 **7 格**，距离任何塔至少 **1 格**；落地后所有出生点都必须仍能走到出口，否则换一个候选点（初版是 5 格：迷宫建满上半张桌子后，空地只剩出口两侧的角落，空降点落在那里会直接绕过整条迷宫，模拟里中等策略在第 12 波就被打穿） |
| 预警时间 | 5 秒（噩梦 4 秒，魔境 3 秒），这段时间里玩家**不能**在落点上放塔 |
| 持续时间 | 2～4 波 |
| 出怪比例 | 激活期间，每波 25%～40% 的敌人改从空降点出来 |
| 同时存在上限 | 普通 1 个，困难 2 个，噩梦及以上 3 个 |
| 拆除 | 空降点有"耐久"，玩家可以花 `40 + 5×波数` 金币拆除；新技能"封箱胶带"也能直接封掉 |
| 路线影响 | 落地会占用格子，相当于新增一处障碍和一个起点，**流场立即重新计算**，界面高亮新路线 |

### 2.3 外观
纸箱造型，侧面画着一个敌人图标，表示这里会出哪种怪。预警阶段在地面上画一个虚线圆圈和倒计时数字，落地时伴随震屏和灰尘粒子。

## 3. 随机事件

### 3.1 事件导演（EventDirector）
- 每局开始时，用种子生成一张**事件时间表**：大约每 2～3 波安排一个事件，可以和波次重叠。
- 每个事件都有**权重**、**最早出现波数**、**冷却**、**互斥标签**，以及按难度调整的**强度**。
- 难度新增参数 `eventRate`（事件频率倍率）和 `eventHostile`（坏事件所占比例）。
- 自定义模式里可以单独开关每一种事件。

### 3.2 事件列表

**负面**（增加压力）：
| 事件 | 效果 | 预警 |
|---|---|---|
| 空降纸箱 | 落下一个空降出生点（§2） | 5 秒 |
| 台灯跳闸 | 所有台灯停用 8 秒 | 3 秒 |
| 风扇转起来 | 飞行敌人速度 +40%，并且飞行路线会摆动，持续 12 秒 | 3 秒 |
| 书本倒下 | 随机一摞书倒下，新增一段 1×3 的障碍。保证不会堵死道路；如果压到塔，塔会被推到最近的空格，等级保留 | 4 秒 |
| 作业检查 | 接下来 20 秒，所有敌人护甲 +3 | 立即 |
| 咖啡打翻 | 一块 3×3 区域里的塔瘫痪 6 秒 | 3 秒 |
| 敌军增援 | 本波额外加一组敌人，从随机出生点出来 | 立即 |

**正面**（奖励）：
| 事件 | 效果 | 页面交互 |
|---|---|---|
| 掉落零花钱 | 棋盘上随机出现 3～5 枚硬币，12 秒内**点击收集** | 点硬币 |
| 灵感闪现 | 随机一座塔获得半级经验 | 无 |
| 午休铃 | 所有地面敌人睡着 4 秒 | 无 |
| 老师表扬 | 本波得分 ×2 | 无 |
| 补给箱 | 出现一个箱子，点开后从 3 个随机小奖励中选一个 | 点箱子 |

**中性**（改变局势）：
| 事件 | 效果 |
|---|---|
| 桌面整理 | 把一个随机杂物移到新位置（同样要通过可达性校验） |
| 窗外起风 | 15 秒内所有弹道类子弹向一侧偏移，命中率下降，光束不受影响 |
| 暗门 | 开启一个隐藏出生点，持续 3 波 |

### 3.3 页面表现（UI）
- **事件横幅**：屏幕顶部滑下一条卡片，包含图标、名称、一句话说明和倒计时，3 秒后缩成状态栏里的小图标。
- **事件时间轴**：下一波预告旁边显示"接下来的已知事件"。只预告确定会发生且已经进入预警的事件，不剧透整张时间表。
- **可点击掉落物**：硬币、补给箱画在棋盘上，点击触发 `collect` 指令。电脑上也可以用鼠标悬停加空格键收集。
- **预警**：棋盘上用虚线圈或红色闪烁框标出影响范围，并显示倒计时。
- **历史**：暂停菜单里能看到本局发生过的所有事件。

## 4. 自动波次

### 4.1 流程
```
开局：建造阶段没有时间限制，玩家点「开始」后进入自动模式
   ↓
第 N 波开始 ──→ 本波全部敌人刷出来以后，开始「下一波倒计时」T_gap
   │              （倒计时期间可以继续建造，也可以点「提前开波」拿奖励）
   │
   └─ 保险：从本波开始算起，过了上限时间 T_max，无论场上还有多少敌人，都强制开下一波
```

| 参数 | 普通 | 困难 | 噩梦 | 魔境 | 说明 |
|---|---|---|---|---|---|
| `waveGap`（刷完到下一波） | 20 秒 | 17 秒 | 16 秒 | 15 秒（每级 −0.3，最低 10） | 倒计时 |
| `waveMax`（每波上限时间） | 60 秒 | 55 秒 | 55 秒 | 55 秒（每级 −1，最低 40） | 防止一直拖着不开下一波 |
| `firstWaveManual` | 是 | 是 | 是 | 是 | 第一波必须由玩家开始 |

> 校准说明：倒计时从"本波刷完"开始算，而迷宫路线要走 30～40 秒，所以场上通常同时有 1～2 波敌人。初版的 15 / 12 / 10 / 8 秒让波次重叠过深，平衡模拟里普通 · 中等策略中位只有约 40 波、魔境 I · 高手卡在第 28 波（空袭波和上一波的残兵同时到），因此按上表放宽（简单难度默认手动开波，参数 20 秒 / 75 秒不变）。

- 设置里可以选**"手动开波"**（简单难度和新手引导默认用手动）或**"自动开波"**（其他难度默认）。排行榜按开波方式分开记录。
- **Boss 波**之前的倒计时 ×1.5，给玩家留出准备时间。
- **增益三选一**时倒计时暂停。
- 倒计时剩 3 秒时，开波按钮闪烁并发出提示音。
- 提前开波奖励改为按**剩余倒计时**计算：`剩余秒数 × (1 + w/10)`。
- 同时进行中的波次上限保持 3 波。达到上限时不会再自动开新波，倒计时停在 0，显示"场上敌人过多"。

### 4.2 对中途存档的影响
自动开波由逻辑层根据帧号决定，**不写入指令记录**，回放时会自然重现。玩家手动提前开波仍然作为指令记录。

## 5. 随机地形

### 5.1 地图 = 固定骨架 + 随机杂物
| 部分 | 每局是否变化 | 内容 |
|---|---|---|
| 骨架 | 不变 | 出口、边缘出生点、章节标志物（例如第二章的键盘） |
| 杂物 | **按种子变化** | 水杯、课本、橡皮、笔筒、便利贴堆、手机、尺子……每张地图有自己的杂物池 |

### 5.2 生成算法（带约束的随机摆放）
1. 按地图的"杂物预算"（例如 6～9 格面积）从杂物池里抽杂物，杂物尺寸为 1×1 到 2×3。
2. 逐个尝试随机位置和朝向（最多 50 次），必须满足：
   - 不压出生点和出口，并且离它们至少 1 格；
   - 放下后，所有出生点仍然能走到出口；
   - 最短路线长度不少于 14 格（防止太容易），也不超过 30 格（防止杂物替玩家把迷宫造好了）；
   - 可建造的格子不少于总格数的 70%；
   - 杂物之间至少隔 1 格，避免挤成一团。
3. 生成后再做一次评分：最短路线长度、可建造面积、"关键缺口"数量都要在目标区间内，不合格就换子种子重新生成（最多 20 次，仍不合格则回退到手工默认布局）。
4. **战役模式**：每一章的骨架固定，杂物按"章节种子 + 局种子"生成。如果玩家希望每次都一样，可以在设置里选择"固定布局"。
5. **无尽 / 自定义**：完全随机。地图选择界面会显示布局缩略图，可以"换一个"（换子种子）。

### 5.3 与排行榜的关系
种子决定地形，所以用同一个种子和别人比拼时，地形完全相同。排行榜记录种子，可以复制种子挑战同一张图。

## 6. 接口变化（types.ts，增量）

```ts
// 状态
interface SpawnerState { id: string; kind: 'edge' | 'hidden' | 'drop'; cells: {x:number;y:number}[];
  active: boolean; warnUntil?: number; expiresAfterWave?: number; hp?: number; icon?: EnemyId }
interface RandomEventState { uid: number; id: RandomEventId; phase: 'warn' | 'active' | 'done';
  startsAt: number; endsAt: number; area?: { x: number; y: number; w: number; h: number } }
interface PickupState { uid: number; kind: 'coin' | 'crate'; x: number; y: number; until: number; value: number }

WorldState += {
  spawners: SpawnerState[];
  events: RandomEventState[];
  pickups: PickupState[];
  autoWave: { enabled: boolean; nextAt: number | null; waveDeadline: number | null };
}
WavePreviewGroup += { spawner: string }      // 每组从哪个出生点出来

// 指令
Command += { type: 'collect'; uid: number }
         | { type: 'demolishSpawner'; id: string }
         | { type: 'chooseCrate'; uid: number; option: number }

// 事件
GameEvent += { type: 'randomEvent'; id: RandomEventId; phase: 'warn' | 'start' | 'end'; ... }
           | { type: 'spawnerDrop'; id: string; x: number; y: number; phase: 'warn' | 'land' | 'close' }
           | { type: 'terrainChanged'; reason: 'event' | 'drop' }
           | { type: 'autoWaveTick'; secondsLeft: number }

// 开局
RunOptions += { autoWave?: boolean; fixedLayout?: boolean; events?: Partial<Record<RandomEventId, boolean>> }
DifficultyParams += { spawnMode; maxActiveSpawners; maxDrops; dropWarn; eventRate; eventHostile; waveGap; waveMax }
```
