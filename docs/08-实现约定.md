# 08 · 实现约定（模块边界与接口）

本章写给开发者，规定三个模块（core / render / ui）之间如何分工、通过什么接口通信。**唯一的接口来源是 `src/core/types.ts`**，任何跨模块改动都要先改那里。

## 目录与归属

| 路径 | 归属 | 说明 |
|---|---|---|
| `src/core/**`、`src/config/**` | core | 纯逻辑与数值配置。**禁止**引用 DOM、Phaser、`Math.random`、`Date.now` |
| `src/render/**` | render | Phaser 棋盘渲染、特效、棋盘上的指针输入 |
| `src/ui/**`、`src/meta/**`、`src/main.ts`、`index.html`、`src/styles/**` | ui | HTML 界面、菜单、存档、永久天赋、排行榜、全局快捷键 |
| `src/game/Session.ts`、`src/game/UiStore.ts`、`src/core/types.ts` | 共享（改动需同步各方） | 运行循环、交互状态、接口类型 |
| `art/**` | 美术 | SVG 源文件，渲染层和界面直接引用 |

## 运行循环
- `Session.update(dtMs)` 由渲染层在 Phaser 场景的 `update` 中每帧调用。它负责按速度（1×/2×/3×）推进固定步长，并把 `world.drainEvents()` 分发给 `session.on()` 的订阅者。
- UI 不轮询 `world.state` 的每个字段；建议用 `requestAnimationFrame` 节流刷新 HUD（每帧比较几个关键数值，有变化才改 DOM）。

## 交互（`ui` store，见 `src/game/UiStore.ts`）
| 场景 | 棋盘上的指针行为（render 实现） |
|---|---|
| `aiming` 不为空 | 按技能目标类型瞄准。鼠标：悬停预览、点击释放；触摸：第一次点设 `pending` 并预览，再点同一格释放。`tower` 类技能点塔；`tower+cell`（搬家）先点塔写入 `relocateFrom`，再点空格 |
| `perkTargeting` 不为空 | 点塔 → `choosePerk {id, uid}` |
| `build` 不为空 | 放塔；鼠标直接放，触摸二次确认。放完**保持选中**，方便连续造墙；Esc、右键或再点塔栏按钮取消 |
| 都为空 | 点塔 → `selected = uid`；点空地 → `selected = null` |

- 全局快捷键由 ui 处理：`1`–`9`、`0`、`-` 选塔；`Q`/`W`/`E`/`R` 技能；空格开波；`F` 切换速度；`P` 暂停；`Esc` 清除状态；`U` 升级选中的塔；`S` 出售。
- 放置失败时，render 在格子上闪红，并通过 `session.command` 的返回值显示原因（toast 由 ui 订阅 `toast` 事件显示；render 直接显示失败文字也可以）。

## 坐标与尺寸
- 逻辑单位为"格"。渲染按 `CELL_PX = 48` 换算，棋盘大小 576×672，整体缩放以适应容器。
- 棋盘容器的尺寸由 ui 的 CSS 布局决定，render 监听容器尺寸变化（ResizeObserver）并重新适配。
