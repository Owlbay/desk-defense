# 11 · 传奇进化：分支之后的成长

> 状态：**已实现**（★1～★3 进化、特性与主动能力；数值见 docs/guide/数据）。本章扩展第 02 章 §1.3 的"熟练度"：熟练度被"进化"取代。

## 1. 规则

选定传奇分支（Lv10）之后，塔还可以沿着**自己的分支**继续进化 3 星：

| 阶段 | 名称 | 获得 | 外观 |
|---|---|---|---|
| Lv10 | 传奇 | 分支本身的能力（第 02 章） | T4 传奇 A/B |
| ★1 | 传奇·一星 | 属性提升 + **分支特性一** | T4 外观，底座旁多 1 颗金星 |
| ★2 | 传奇·二星 | 属性提升 + **分支特性二** | 2 颗金星，光环更亮，粒子更多 |
| ★3 | **神话** | 属性提升 + **主动能力** | **全新外观 T5（神话 A/B）**，常驻动画 |

### 1.1 进化途径（与等级相同：经验和金币两条路）
- **经验**：Lv10 之后获得的经验全部计入"进化经验"，不再转为熟练度。
  - 所需经验：★1 500、★2 1000、★3 1750（已按模拟校准：普通 · 中等策略里最好的一座传奇塔第 33 波左右到 Lv10，之后每波约 100～200 进化经验；初版 2000 / 4000 / 7000 要到第 55 波以后才到 ★2）。
- **金币**：可以直接花钱进化，费用为该塔传奇升级费用的 ×0.8 / ×1.0 / ×1.3，同样享受经验折扣（经验进度越高越便宜，最多 −50%）。
- **★3 必须花金币**，和 Lv10 一样，保证"神话"是一个主动决定。
- 难度的 `xpMul` 和天赋"勤学"同样对进化经验生效。

### 1.2 每颗星的属性提升
伤害 ×1.12，射程 +0.1 格，攻击间隔 ×0.97。辅助塔和经济塔改为提升光环或产出数值 +10%。

### 1.3 出售
返还率在 Lv10 时为 25%，进化不再继续降低，保持 25%；"已投入"包含进化花的金币。

### 1.4 主动能力（★3 解锁）
- 选中神话塔后，信息面板出现能力按钮（显示图标、冷却），电脑上也可以按 `A`。
- 能力分为**无需目标**和**需要点一个位置 / 一条线**两种，后者的瞄准方式与玩家主动技能相同（第 05 章 §1.1）。
- 冷却只在战斗阶段计时；同一座塔的能力不叠加。
- 场上神话塔的能力会显示在技能栏右侧的"塔能力"区，最多 4 个，可以不选中塔直接释放。

## 4. 接口变化（types.ts，增量）

```ts
type Tier = 1 | 2 | 3 | 4 | 5;                     // 5 = 神话

TowerState += {
  stars: 0 | 1 | 2 | 3;
  evoXp: number; evoXpNext: number;                // 取代 mastery

TowerInfo += {
  stars: number;
  evolveCost: number | null;                       // null = 已满星

              target: 'none' | 'circle' | 'line' | 'axis' | 'enemy' | 'tower'; ready: boolean };

         | { type: 'towerAbility'; uid: number; x?: number; y?: number; angle?: number;
             axis?: 'row' | 'col'; index?: number; targetUid?: number }

GameEvent += { type: 'evolve'; uid: number; stars: number; mythic: boolean }
           | { type: 'towerAbility'; uid: number; ability: string; x?: number; y?: number }
```

## 5. 平衡目标
- 普通难度下，一座位置好的传奇塔靠经验大约在第 45 波前后到 ★2；★3 需要额外投入大约 1.5 倍传奇升级费用。
- 同一座塔的两个分支在神话阶段的模拟表现差距控制在 15% 以内。
- 主动能力单次释放的价值大约相当于玩家主动技能"大橡皮"的 1～1.5 倍，不能取代玩家技能。
- 无尽模式第 60 波以后，主要的成长空间来自进化，用来拉长后期的养成目标。

### 5.1 校准现状（`npm run sim`、`npx vite-node scripts/bench.ts -- --only mythic`）
数值全部在配置里：分支 / 星级特性 `BRANCH`（`src/config/towers.ts`），苍蝇拍 `SWATTER`，主动能力强度 `ABILITY_FX`（`src/config/evolution.ts`）。说明文字直接引用这些数。`bench.ts` 支持 `--patch '{"fx.glue_a.root":6,"branch.glue.B.dps":6}'` 临时试数值、`--towers glue,lamp` 只跑部分塔。

神话对比的方法：3 座 ★3 + 8 座 Lv5 铅笔（苍蝇拍：1 座 ★3 + 8 座 Lv5 订书机，否则飞行敌人全被打光，防空能力无从衡量），**只有第一座塔放能力**（三座同时放的全场效果会互相重叠，单次价值被低估三倍），机器人对全场能力会等场上至少 6 个敌人（苍蝇拍等 3 个飞行敌人）再放。
